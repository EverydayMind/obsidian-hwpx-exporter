## What's new

- **Writing Skills for AI hosts.** The plugin now offers its HWPX document-writing and format-reuse Skills to an AI host that supports plugin-provided Skills, so the host can load them without you copying anything into your vault.
- **Settings show host support.** The settings tab now says whether an enabled AI host supports plugin-provided Skills.

No agent tool definition changed, but as after every update, Verbex asks you to approve HWPX Exporter again before the agent can use its tools.
