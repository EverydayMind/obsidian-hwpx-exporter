## What's new

- **Settings in the app language, in plain words.** The settings tab follows the Obsidian language (Korean in a Korean Obsidian), and setting names and descriptions use everyday wording instead of developer terms.
- **"Export to HWPX (with template)" in the file menu.** The file explorer menu items now say what they do, so they are easy to tell apart from other export plugins.
- **Warnings show examples.** When something is left as literal text (for example wikilinks), the conversion warning notice shows up to two examples of what remained.
- **Clearer notices.** Notices name the install-templates command in the app language, and the first-run notice explains what the installed template files are for.

## Fixes

- **Correct template count right after installation.** The count under **Template folder** showed 0 until the settings tab was reopened.

No agent tool definition changed, so an agent host does not need to re-approve the plugin's tools.
