## What's new

- **Render-capture warnings name the real cause.** Instead of "Rendered-block capture is disabled", the export warning now says which setting blocked each chart or diagram: rendered-block capture, Mermaid capture, or third-party renderer capture (for example Plotly).
- **"Turn on render capture" asks first.** The button turns on only the settings the skipped blocks need, after a confirmation inside the same notice. Turning on third-party renderers shows a reminder to use it only for notes you trust.
- **Failure reasons in the notice.** When a block cannot be captured, the export warning lists the block and the reason (up to 10), for single and batch exports, instead of only pointing to the developer console.
