## What's new

- **"Export again now" overwrites the same file.** After you turn on render capture from the warning, the **Export again now** button re-exports the note to the same file instead of creating a `-2.hwpx` copy (single-note export).
- **Menu items name the plugin.** The file explorer menu items are now titled "HWPX Exporter: Export with template" and "HWPX Exporter: Export folder with template", and the editor context menu has the same "HWPX Exporter: Export with template" item for Markdown notes.
- **Notices no longer point to the developer console.** Notices describe what happened and what to do in plain words.

No agent tool definition changed, so an agent host does not need to re-approve the plugin's tools.
